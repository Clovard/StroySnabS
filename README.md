# StroySnabS — доработки 1С УТ ↔ Bitrix24

Материалы для переноса на RDP и установки в расширение **Б24Доработки**.

## С чего начать на RDP

1. Откройте **`Б24_доработки/ВСТАВИТЬ_В_1С/00_ИНСТРУКЦИЯ.txt`** — пошаговая установка в конфигуратор.
2. Код вставляется **только из папки `ВСТАВИТЬ_В_1С/`** (файлы 01–07).
3. Модули КП и оплаты — из **`Б24_доработки/modules/`** (см. инструкцию, шаг 7).
4. Настройка коннектора B24 — **`04_КОННЕКТОР_ДВУСТОРОННИЙ.txt`**.

## Структура

```
Б24_доработки/
├── ВСТАВИТЬ_В_1С/          ← главное: что копировать в 1С
│   ├── 00_ИНСТРУКЦИЯ.txt
│   ├── 01 … 07_*.txt       ← код модулей и форм
│   └── 04_КОННЕКТОР_*.txt  ← настройки B24 (не код)
├── modules/                ← доп. модули (КП, оплата, счёт)
├── КОНСТАНТЫ.md            ← константы для кнопки КП
└── README.md               ← описание расширения
```

## Что делает

| Функция | Файлы |
|---------|--------|
| 20 стадий канбана ↔ 1С | 01, 02, 03, подписки |
| 1С → B24 и B24 → 1С | 01 + коннектор |
| Дата оплаты на заказе | `modules/Б24_ОплатаСервер.bsl` |
| Счёт с факсимиле только с датой | 07, 06 |
| Кнопка «Сформировать КП» | 03 + `modules/Б24КП_*` |

## После клонирования на RDP

```bash
git clone https://github.com/Clovard/StroySnabS.git
```

Скопируйте папку `Б24_доработки` куда удобно и работайте по `00_ИНСТРУКЦИЯ.txt`.
