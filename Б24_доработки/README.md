# Расширение «Б24_доработки» — полная сборка

Одно расширение: **дата оплаты**, **КП в B24**, **статусы канбана (20 = стадии B24)**.

Префикс: `Б24_` (модули КП — `Б24КП_`, исторически).

### ⚠️ Реквизит и перечисление стадии — актуальные имена

Ниже — то, что реально читает и пишет код (`Б24_СинхронизацияСервер.bsl`, форма
заказа, кнопка КП). Модуль `Б24_СтатусыСервер.bsl` использовал другие имена
(`Б24_СтатусКанбана` / перечисление `Б24_СтатусыКанбана` без префикса у
значений) — он **устарел**, его подписку нужно удалить (см.
`ВСТАВИТЬ_В_1С/00_ИНСТРУКЦИЯ.txt`), а сам модуль в расширении не нужен.
Если в базе уже создан реквизит/перечисление по старой схеме — их нужно
переименовать/пересоздать под имена ниже, иначе код их просто не увидит.

## 2. Коннектор Bitrix24

Обмен строго односторонний: **1С → B24**. Из Bitrix24 в 1С ничего не
принимается — ни стадия сделки, ни любые другие поля заказа (код в
`Б24_СинхронизацияСервер` откатывает любую попытку импорта).

**Синхронизация сделок → Сопоставление статусов:**
1. Источник: **Дополнительный реквизит заказов** = **`Б24Д_Статус`**.
2. **20 стадий B24 = 20 значений** — 1:1 по названию.
3. Коннектор B24 — **вкл**, безопасный режим **выкл**.
4. В «Синхронизация сделок»: **«Выгружать сделки в Bitrix24» — вкл**,
   **«Загружать сделки из Bitrix24» — выкл** (см. `ВСТАВИТЬ_В_1С/04_КОННЕКТОР_ДВУСТОРОННИЙ.txt`).

> Если коннектор требует «Дополнительное значение» БСП — продублируйте значения в доп. реквизите и синхронизируйте из `Б24Д_Статус` (доработаем при необходимости).

## 4. Проверка

| Тест | Ожидание |
|------|----------|
| Заказ → дата оплаты → оплата с заказа | Платёжка с **этой датой** |
| Оплата/отгрузка | **Состояние** меняется → **Статус канбана** на заказе |
| Обмен B24 (1С → B24) | Стадия сделки = статусу канбана |
| Обмен B24 (B24 → 1С) | НЕ должно ничего менять в 1С — перетащили сделку в B24, «Стадия» в 1С не поменялась |
| Кнопка КП | PDF + файл в таймлайне сделки |
| Печать счёта (с факсимиле или обычного) при привязанном заказе | PDF + файл в таймлайне той же сделки, без доп. действий менеджера |
