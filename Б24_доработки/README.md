# Расширение «Б24_доработки» — полная сборка

Одно расширение: **дата оплаты**, **КП в B24**, **статусы канбана (20 = стадии B24)**.

Префикс: `Б24_` (модули КП — `Б24КП_`, исторически).

### Форма `ФормаДокумента`
- **Объект** → «Добавить в расширение»
- Поле `Б24_ДатаФактОплаты` (где уже стоит)
- Поле `Б24_СтатусКанбана` — заголовок **«Статус»**, рядом с типовым статусом/состоянием
- Команда + кнопка `Б24_СформироватьКП` (на панели или в «Печать»)
- Модуль формы: `form/ЗаказКлиента_ФормаДокумента.bsl`

## 2. Коннектор Bitrix24

**Синхронизация сделок → Сопоставление статусов:**
1. Источник: **Дополнительный реквизит заказов** (или реквизит `Б24_СтатусКанбана`, если коннектор видит реквизиты расширения).
2. **20 стадий B24 = 20 значений** — 1:1 по названию.
3. Коннектор B24 — **вкл**, безопасный режим **выкл**.

> Если коннектор требует «Дополнительное значение» БСП — продублируйте значения в доп. реквизите и синхронизируйте из `Б24_СтатусКанбана` (доработаем при необходимости).

---

## 3. Константы в Предприятии

- `Б24КП_ИнтеграцияВключена` = **Да**
- `Б24КП_ВебхукURL` — для заказов **без ИНН**
- `Б24КП_IDВоронки` — CATEGORY_ID воронки

## 4. Проверка

| Тест | Ожидание |
|------|----------|
| Заказ → дата оплаты → оплата с заказа | Платёжка с **этой датой** |
| Оплата/отгрузка | **Состояние** меняется → **Статус канбана** на заказе |
| Обмен B24 | Стадия сделки = статусу канбана |
| Кнопка КП | PDF + файл в таймлайне сделки |

## 5. Выгрузка `.cfe`

Конфигуратор → **Расширения** → `Б24_доработки` → **Сохранить как…** → `.cfe`

На базе заказчика: **Загрузить из файла** → **F7** → включить в Предприятии.
