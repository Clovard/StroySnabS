================================================================================
ОБНОВЛЕНО 21.08.2026: СХЕМА СТАЛА ОДНОСТОРОННЕЙ — 1С → Bitrix24
================================================================================

Раньше (файл называется «ДВУСТОРОННИЙ») стадия могла прийти и из B24 обратно
в 1С. По требованию — теперь ТОЛЬКО 1С → B24. Из Bitrix24 в 1С НИЧЕГО не
принимается: ни стадия сделки, ни любые другие поля заказа.

Код (файл 01, см. 19_ЗАМЕНИТЬ_КОД_ПОЛНОСТЬЮ.txt) теперь сам откатывает любую
попытку обмена изменить Б24Д_Статус — даже если коннектор всё равно что-то
загрузит. Но коннектор лучше тоже настроить только на выгрузку — см. ниже,
чтобы не гонять лишний трафик и не путать логи.

================================================================================
КАК ЭТО УСТРОЕНО СЕЙЧАС
================================================================================

  1С: поле «Стадия» (Б24Д_Статус) на заказе  — источник истины
           ↓  код расширения
  1С: регистр «Текущее состояние» (для списка заказов)
           ↓  коннектор (доп. реквизит Б24Д_Статус), выгрузка
  Bitrix24 (20 колонок канбана)               — только отражает 1С

Стрелка вверх (B24 → 1С) отсутствует полностью.

================================================================================
НАСТРОЙКА КОННЕКТОРА (один раз)
================================================================================

Синхронизация B24 → Сделки:

  ☐ Загружать сделки из Bitrix24     — ВЫКЛ (навсегда, не только на время сдачи)
  ☑ Выгружать сделки в Bitrix24      — ВКЛ
  ☑ Синхронизация в реальном времени (или вручную)

Сопоставление статусов → нужная воронка:

  1. **Доп. реквизит заказа** = **Б24Д_Статус**
  2. Загрузить с Bitrix24 (чтобы увидеть список стадий B24 для сопоставления)
  3. Сопоставить **20 стадий** ↔ **20 значений Б24_***
  4. Применить и закорить

НЕ сохранять потом вкладку «Статусы заказов» (3 значения) — перебьёт настройку.

Если чек-бокс «Загружать сделки из Bitrix24» вообще выключить нельзя (коннектор
требует хотя бы галку) — не страшно: код в 01 (Б24_СинхронизацияСервер) всё
равно откатывает Б24Д_Статус на значение из 1С при каждой попытке импорта.

================================================================================
ТЕСТ (только одно направление)
================================================================================

**1С → B24**
  1. Заказ 00УТ-001345 → «Стадия» = «Товар на складе» → Записать
  2. Синхронизация (или real-time)
  3. B24: сделка в колонке «Товар на складе»

**Перетаскивание в B24 больше НЕ должно ничего менять в 1С** — это ожидаемое
поведение, а не баг. Если после перетаскивания сделки в B24 стадия в 1С всё
же меняется — не обновился код модуля 01 (F7 + перезапуск 1С).
