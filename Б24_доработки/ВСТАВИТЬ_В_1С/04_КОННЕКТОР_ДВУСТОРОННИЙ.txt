================================================================================
ДВУСТОРОННИЙ ОБМЕН СТАДИЙ: 1С ↔ Bitrix24
================================================================================

Цель:
  • Поменяли «Стадию» в 1С → сделка переехала на канбане B24
  • Перетащили сделку в B24 → «Стадия» в 1С обновилась

================================================================================
КАК ЭТО УСТРОЕНО
================================================================================

  Bitrix24 (20 колонок канбана)
           ↕  коннектор (доп. реквизит Б24Д_Статус)
  1С: поле «Стадия» (Б24Д_Статус) на заказе
           ↕  код расширения
  1С: регистр «Текущее состояние» (для списка заказов)

Единая точка для людей и для B24 — реквизит **Б24Д_Статус**.

================================================================================
НАСТРОЙКА КОННЕКТОРА (один раз)
================================================================================

Синхронизация B24 → Сделки:

  ☑ Загружать сделки из Bitrix24     (B24 → 1С)
  ☑ Выгружать сделки в Bitrix24      (1С → B24)
  ☑ Синхронизация в реальном времени (или вручную)

Сопоставление статусов → воронка «Тестовая воронка СТРОЙС»:

  1. **Доп. реквизит заказа** = **Б24Д_Статус**
  2. Загрузить с Bitrix24
  3. Сопоставить **20 стадий** ↔ **20 значений Б24_***
  4. Применить и закорить

НЕ сохранять потом вкладку «Статусы заказов» (3 значения) — перебьёт настройку.

================================================================================
КОД РАСШИРЕНИЯ (файлы 01, 02, 03 + подписки из 00)
================================================================================

  1С → B24:  смена «Стадии» → регистр → **автовыгрузка только на B24** (без импорта)
  B24 → 1С:  коннектор пишет Б24Д_Статус → код обновляет регистр

  После «Записать» заказа с новой стадией код сам запускает выгрузку сделок
  (фоновое задание, ВыполнятьЗагрузку=Нет, ВыполнятьВыгрузку=Да).
  Ручная «Синхронизация» тоже подойдёт, но уже не обязательна для 1С→B24.

  Защита от отката: если только что меняли в 1С, импорт старой стадии с B24
  не затирает — до тех пор, пока выгрузка не дойдёт до портала.

================================================================================
ТЕСТ (оба направления)
================================================================================

**1С → B24**
  1. Заказ 00УТ-001345 → «Стадия» = «Товар на складе» → Записать
  2. Синхронизация (или real-time)
  3. B24: сделка в колонке «Товар на складе»

**B24 → 1С**
  1. Перетащить сделку в «К обработке»
  2. Синхронизация
  3. 1С: «Стадия» = «К обработке», «Текущее состояние» совпадает
