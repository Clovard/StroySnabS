================================================================================
СРОЧНО ПЕРЕД СДАЧЕЙ (15 минут) — 1С → B24
================================================================================

ПРОБЛЕМА (что на скринах):
  1. Меняешь «Стадию» в 1С → Провести
  2. Синхронизация: «Записан заказ 00УТ-001345» (ИМПОРТ с портала)
  3. B24 затирает 1С старой стадией → канбан не едет

================================================================================
ШАГ A. Код (5 мин) — ОБЯЗАТЕЛЬНО
================================================================================
1. Файл 01 → Б24_СинхронизацияСервер → F7
2. Файл 03 → модуль формы ЗаказКлиента → F7
3. Перезапуск 1С

================================================================================
ШАГ B. Коннектор (3 мин) — чтобы 1С → B24 выгружало
================================================================================
Синхронизация B24 → Сделки → Сопоставление статусов:
  Доп. реквизит заказа = **Б24Д_Статус**
  20 стадий сопоставить → Применить

☑ Выгружать сделки в Bitrix24 — ВКЛ

================================================================================
ШАГ C. На время сдачи — отключить откат из B24 (2 мин)
================================================================================
Синхронизация B24 → Сделки:
  ☐ **Загружать сделки из Bitrix24** — ВЫКЛ (временно!)

Так импорт перестанет откатывать стадию после каждого «Провести».
После сдачи включишь обратно + донастроим B24→1С.

================================================================================
ШАГ D. Тест перед демо (2 мин)
================================================================================
1. Заказ 00УТ-001345
2. Стадия → «Передано в логистику с завода» (или нужная)
3. **Записать** (можно Провести)
4. Синхронизация → **Выполнить синхронизацию**
5. B24: сделка в нужной колонке

Ошибки PRESET_ID / LogoDto по «тест стройснаб» — не блокируют сделки,
это контрагент без полных реквизитов. На стадию не влияет.

================================================================================
Если стадия в 1С всё равно откатывается после F7
================================================================================
Проверь подписки в расширении (файл 00):
  Б24_ЗаказПередЗаписью  → ПередЗаписью
  Б24_ЗаказПриЗаписи     → ПриЗаписи
  Б24_СостоянияПриЗаписи → регистр ПриЗаписи

Удалить старую: Б24_СинхСостояния → Б24_СтатусыСервер
