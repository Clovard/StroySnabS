# Константы расширения Б24КП_ФормированиеКП

| Имя | Тип | По умолчанию | Назначение |
|-----|-----|--------------|------------|
| Б24КП_ИнтеграцияВключена | Булево | Ложь | Главный выключатель функции «Сформировать КП» |
| Б24КП_ВебхукURL | Строка (500) | "" | Входящий вебхук Bitrix24, пример: `https://bitrix.stroysnab66.ru/rest/1/xxxxx/` |
| Б24КП_IDВоронки | Строка (20) | "" | CATEGORY_ID воронки CRM для сценария **без ИНН** |
| Б24КП_ИмяПечатнойФормыКП | Строка (100) | КоммерческоеПредложение | Имя штатной ПФ УТ (если есть); иначе используется встроенный макет модуля |

## Права вебхука B24

Минимум scope:
- `crm` (crm.deal.add, crm.timeline.comment.add)
- при необходимости `disk` (если политика портала требует отдельной загрузки файлов)

## Где заполнять

После установки расширения: **НСИ и администрирование → Константы** (или через Конфигуратор → Константы расширения).
